# Resolvendo Códigos em Python com o GitHub Copilot - DIO

Repositório desenvolvido para o desafio de projeto **"Utilizando as Ferramentas do GitHub para Solucionar Algoritmos em Python"** da formação **GitHub Certification** na Digital Innovation One (DIO).

---

## 🎯 Objetivo do Projeto

Explorar a integração entre o **GitHub Copilot**, o **GitHub Codespaces** e a linguagem **Python** para acelerar o desenvolvimento, obter sugestões inteligentes de código e documentar a resolução de algoritmos clássicos de lógica de programação.

---

## 🛠️ Ferramentas e Tecnologias Utilizadas

* **Python 3:** Linguagem utilizada para implementar a lógica dos algoritmos.
* **GitHub Copilot:** Assistente de inteligência artificial utilizado para gerar sugestões de código, otimizar soluções e auxiliar na documentação.
* **GitHub Codespaces:** Ambiente de desenvolvimento em nuvem utilizado para editar e testar os scripts.
* **Git & GitHub:** Controle de versão e hospedagem do repositório.

---

## 📂 Algoritmos Implementados

1. **`1_concat_dados.py` — Concatenando Dados**
   * **Descrição:** Recebe dois dados distintos informados pelo usuário e os concatena em uma única string de saída.
2. **`2_repet_txt.py` — Repetindo Textos**
   * **Descrição:** Solicita uma string e um número inteiro como entrada e retorna o texto repetido a quantidade de vezes especificada.
3. **`3_ope_mat.py` — Operações Matemáticas Simples**
   * **Descrição:** Recebe dois números e realiza operações aritméticas básicas (`+`, `-`, `*`, `/`), incluindo tratamento para evitar divisão por zero.
4. **`4_par_impar.py` — Verificando Números Pares e Ímpares**
   * **Descrição:** Analisa um número inteiro informado e verifica se ele é par ou ímpar utilizando o operador de resto da divisão (`%`).
5. **`5_media_notas.py` — Calculando Média de Notas**
   * **Descrição:** Calcula e exibe a média aritmética de três notas inseridas pelo usuário.
6. **`6_palindromo.py` — Verificando Palíndromos**
   * **Descrição:** Verifica se uma palavra é um palíndromo (lê-se igual de trás para frente) comparando a string original com sua versão invertida (`[::-1]`).
